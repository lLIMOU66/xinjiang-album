# 交接清单：动手之前，先把这些东西备齐

> 这份文档是给"要做一个同样效果相册站"的人看的。
> 结论先说：**网站本身不需要花钱、不需要服务器、不需要数据库、不需要绑银行卡**，
> 但有两个账号必须在**你本人**手里注册完成——AI 没法替你注册，也不会替你要密码。

---

## 一、先准备素材（唯一必需的输入）

一个文件夹，里面是这次旅行的照片和视频。结构随意，但**文件名必须带日期**：

```
D:\我的相册\2026 青甘大环线\
├── 2026-04-13 盐湖\        ← 文件夹名带日期最好，脚本会先读文件名
│   ├── IMG_20260413_001.jpg
│   ├── IMG_20260413_002.jpg
│   └── VID_20260413_001.mp4
└── 2026-04-14 雪山公路\
    ├── IMG_20260414_001.jpg
    └── VID_20260414_001.mp4
```

- 日期格式：`20260413` / `2026-04-13` / `2026_04_13` 都认。
- **读不出日期的文件会被归到一个默认分类里**，分类会乱——这一步错了，后面全要重做。
- 视频单段超过 **25MB** 的一定有（iPhone 随便拍就超），这些要走 Cloudinary，见第二节。
- 原图不用处理，脚本会压成 WebP；视频也不用转，脚本会转 1080p。

---

## 二、Cloudinary（只有"大视频"需要它）

**为什么需要**：Cloudflare Pages 单文件硬限制 25MB，超过的视频传不上去，必须有第二个地方放视频。

**但先看额度，再决定要不要用它**（免费版硬限制，2026-11 核实）：

| 限制 | 数值 |
|---|---|
| 单视频 | 100 MB |
| 单图片 | 10 MB |
| 每月额度 | **25 credits，1 credit = 1 GB 存储 或 1 GB 流量 或 1000 次变换，三者共用一个池** |
| 超额后果 | **不是自动扣费，是警告后停号**——全站视频会一起失效 |

所以**视频要尽量压进 24 MB 留在 Pages**（Pages 静态流量不限量），只有实在压不下去的长段才上传 Cloudinary。
实测参考：2.43 GB 视频若全放 Cloudinary，存储占 2.43 credits，**约 1000 次访问（每次看 3 段）就会烧穿 25 credits**。
分档参数和换算见 [`编码与压缩推荐.md`](编码与压缩推荐.md)。

> 网上教程常写"免费 25 GB 存储 + 25 GB 流量"，那是旧计费模型，别按那个估。

**怎么注册**：打开 https://cloudinary.com/users/register_free ，邮箱注册，选 Free 计划。**免费额度足够个人相册，不需要绑银行卡。**

注册完进 Dashboard，首页顶部就能看到 **Cloud name**；API Key / API Secret 在首页的 "Product Environment Credentials" 区块（或右上角齿轮 → Access Keys）。

你要抄下来的三个值：

| 名称 | 长什么样 | 在哪 |
|---|---|---|
| Cloud name | 一串小写字母，如 `dxxxxxx` | Dashboard 首页顶部 |
| API Key | 15 位数字 | Dashboard 首页凭据区 |
| API Secret | 一串字母数字 | 同上，点 "eye" 才显示 |

> 这三个是"上传凭证"。AI 执行脚本时要临时用一下，**用完请你自己撤销或轮换**，不要写进任何会公开的文件。

## 三、Cloudflare（部署必需）

网站最后要放到 Cloudflare Pages 上，才有一个别人能打开的网址。

**怎么注册**：https://dash.cloudflare.com/sign-up ，邮箱注册即可，免费计划够用，**同样不需要绑卡**。

要准备三个值：

| 名称 | 在哪找 | 注意 |
|---|---|---|
| 邮箱 | 就是你注册用的邮箱 | — |
| **Global API Key** | 右上角头像 → My Profile（我的个人资料）→ 页面**最下面** API Keys → Global API Key → View | **不是**上面那一大片 "API Tokens" |
| Account ID | Dashboard 首页右侧栏 → Account ID | 32 位十六进制 |

> **这一步是绝大多数人卡住的地方。**
> Cloudflare 面板上最显眼的是 "API Tokens"（可以精细授权的那种），但 `wrangler` 用的老式命令需要的是藏在个人资料页底部的 **Global API Key**。
> 拿错的表现：`Authentication error [code: 10000]` 或 `Invalid request headers`。看到这个报错，先回头确认拿的是不是 Global API Key。

安全提醒：Global API Key 权限很大。用完可以在同一页面点 "Change" 轮换掉；本机执行时用临时环境变量，不要写进任何文件。

## 四、本地工具（AI 可以装，但要有网）

| 工具 | 用途 | 装法 |
|---|---|---|
| Python 3 | 跑构建脚本 | python.org 下载，装时勾选 Add to PATH |
| Pillow | 压图、抽帧 | `pip install pillow` |
| ffmpeg | 转视频 | 官网下载解压后把 `bin` 加进 PATH，或直接填绝对路径 |
| wrangler | 部署到 Cloudflare | `npm i -g wrangler`（需要 Node.js） |

**ffmpeg 一定要用官方版或完整版**。剪映、录屏工具里自带的 ffmpeg 通常只带显卡编码器（`h264_nvenc`），跑脚本会报 `Unknown encoder 'libx264'`，转出来的视频也没法保证清晰度。

## 五、谁做什么：哪些必须你本人动手

| 事情 | AI 能做 | 必须你本人 |
|---|---|---|
| 装依赖、跑扫描/压图/转码/抽帧/生成数据 | ✅ | |
| 逐张看图、给出分类建议 | ✅ | 最终拍板 ✅（你看一眼就知道哪张是饭、哪张是湖） |
| 本地预览、自查报错 | ✅ | |
| 注册 Cloudinary / Cloudflare | | ✅（要邮箱验证） |
| 抄 Cloud Name / API Key / Secret | | ✅（AI 不该长期持有密钥） |
| 抄 Global API Key / Account ID | | ✅ |
| 跑 `wrangler kv namespace create`（会弹浏览器登录） | 帮你敲命令 | ✅（登录授权这一步只能你点） |
| 填 `wrangler.toml` 里的 KV id | ✅（你把 id 给 AI） | |

一句话记法：**账号是你的、密钥是你的、登录授权是你的；剩下的活都可以交给 AI。**

## 六、第一次跑的推荐顺序

1. **先只跑本地**：`scan → photos → videos → posters → data`，然后 `python tools/serve.py`，电脑上先看效果。
   - 这一步不需要任何账号，跑通了说明素材和分类都没问题。
2. 有超 25MB 的视频，才去注册 Cloudinary、跑上传脚本。
3. 效果满意了再注册 Cloudflare、建 KV、部署。
4. **部署一律用 `wrangler pages deploy`，不要用网页拖拽**：拖拽上限只有 1,000 个文件，
   而一个几百张照片的相册站很容易超过（本项目线上站 2,016 个文件），超了会静默漏文件。
   Wrangler 的上限是 20,000 个文件 / 单文件 25 MiB。
5. 部署完用手机 4G 打开验收（照片、视频、点赞、留言各测一次）。

## 七、最常撞的报错对照表

| 现象 | 原因 | 怎么修 |
|---|---|---|
| `git clone` 卡住 / `Failed to connect to github.com:443` | 国内网络直连 GitHub 被墙 | 到仓库页面点 **Code → Download ZIP** 下载，解压后用 |
| `CRYPT_E_NO_REVOCATION_CHECK` 或 `unable to get local issuer certificate` | 本机查不到证书吊销列表（网络中间有拦截） | 命令加 `-c http.sslVerify=false`<br>`git -c http.sslVerify=false clone https://github.com/lLIMOU66/xinjiang-album.git` |
| `push` 报 `could not read Username for 'https://github.com'` | git 没拿到已保存的凭据（非交互模式下 helper 不工作） | 加 `-c credential.helper=manager`<br>`git -c http.sslVerify=false -c credential.helper=manager push origin main` |
| `Unknown encoder 'libx264'` | ffmpeg 是剪映/录屏工具自带的精简版 | 换官方完整版 ffmpeg，或在 `site.config.json` 里填官方版绝对路径 |
| `Authentication error [code: 10000]` | 用了 API Token，不是 Global API Key | 去个人资料页底部拿 Global API Key |
| 上传视频报 `401 Invalid Signature` | 上传脚本签名参数和实际提交的不一致 | 用仓库里的 `tools/upload_cloudinary.py`，不要自己拼 API 请求 |
| 视频传上去了但线上 404 / 黑屏 | 代理路径丢了 `folder` 前缀（`upload/v-x.mp4` 实际是 `upload/album/v-x.mp4`） | 用仓库脚本，它写映射时保留完整 `public_id` |
| 首页全白 | `data.js` 带 BOM，或 JSON 语法被手改坏 | 重跑 `python tools/build_site.py data` |
| 所有素材 404 | Functions 目录层级少了，变成代理整个 `/media/` | 路径必须是 `functions/media/video/[[path]].js` |
| 视频能播但拖不动进度条 | 本地预览用了 `python -m http.server`（不支持 Range） | 用仓库的 `tools/serve.py` |
| 素材都进了同一个分类 | 文件名没有日期，或跳过了"逐张看分类" | 改名带日期 + 重做分类那一张表 |
| 点了赞数字不变 | `wrangler.toml` 里 KV id 还是占位符 | `wrangler kv namespace create "ALBUM_KV"`，把 id 填进去重新部署 |
| 国内打开是红色"网页存在安全风险" | 直接把 `res.cloudinary.com` 写进了数据 | 视频必须走 `/media/video/` 代理 |
